Přes MCP může Claude, ChatGPT nebo kódovací agent hledat v přepisech sám: nástroje search_videos, research_topic (rešerše pro psaní), ask_channel (odpověď s citacemi), get_transcript, list_videos. Server je veřejný, bez přihlášení (Streamable HTTP).
